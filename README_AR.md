# TaL3D - Global Opportunity Hunter | MVP

مشروع منفصل منطقيًا عن cults-radar، وهو بديل الملفات الحالية لرادار الفانتسي.

## يعمل حاليًا
- جمع RSS رسمي من مصادر المعرفة في config/sources.yaml، مع حالة المصدر ووقت الفحص.
- استخراج مرشحي القطع المادية من النصوص، مع مرجع رسمي؛ لا يتم الادعاء بأن الاسم مرئي أو مؤكد.
- تصنيف أولي لإشارات نية امتلاك في المصادر المجتمعية المصرح بها.
- فحص عينات بحث Cults3D إذا أُضيف CULTS_USERNAME وCULTS_API_KEY إلى Secrets هذا المستودع.
- تقرير HTML عربي ومؤرخ، وذاكرة JSON دائمة في data/state.json.
- جدولة Economy مرة واحدة يوميًا الساعة 08:19، وتقرير واحد عند 09:00 بتوقيت الرياض.
- وضع Early Hunter بست دورات يوميًا عند تعيين متغير Actions باسم HUNTER_MODE بقيمة early.
- بريد Gmail بالمفاتيح الموجودة من مشروع الفانتسي: GMAIL_USER وGMAIL_PASS وTO_EMAIL.
- مزيد من التحقق بواسطة pytest، دون أي نشر STL تلقائي.

## التشغيل
Python 3.12. أوامر العمل:
    pip install -e ".[test]"
    python -m pytest -q
    python main.py dry-run
    python main.py collect
    python main.py report
    python main.py status

يمكن تجربة workflows يدويًا من GitHub Actions. متغير HUNTER_NOTIFICATIONS_ENABLED=0 يوقف الإرسال.
تعيد Actions حفظ التقرير أولًا، ثم تحفظ مطالبة فريدة قبل الإرسال، فلا تعيد إرسال يوم سبق أن حاولت إرساله.
نتيجة UNKNOWN تعني أن الخدمة ربما استقبلت البريد رغم فشل قراءة الرد، ولا تعاد المحاولة آليًا.

## الدقة والقيود
هذا إصدار MVP وليس النظام العالمي الكامل.
الاستخراج من العناوين ومقتطفات RSS فقط، ولا يحلل الصور أو الفيديوهات في هذا الإصدار.
فحص Cults3D عينة من النتائج، وتطابق الأسماء ليس تحققًا بصريًا. المصدر الفاشل = غير مفحوص، لا صفر.
لا توجد توصيات DESIGN NOW آلية من الأدلة الضعيفة، ولا تقديرات مبيعات أو أسعار مختلقة.
لا يستخدم الرادار القديم ولا يلمس مستودع cults-radar.
المستودع المُعاد استخدامه عام؛ لا تحفظ فيه نصوصًا شخصية أو مفاتيح.
مفاتيح Cults من مستودع آخر لا تنتقل إليه تلقائيًا.
تاريخ Git السابق ما زال قابلًا للوصول عبر commits القديمة؛ اختفاء الملفات من main لا يعني حذف التاريخ.
تأخر جدولة GitHub Actions ممكن، ولا يُضمن التسليم النهائي للبريد بمجرد نجاح SMTP.

## تحسين الاستيعاب من Horizon (نوفمبر 2026)

استفدنا من تصميم [Thysrael/Horizon](https://github.com/Thysrael/Horizon) (MIT)
بوصفه مرجعًا معماريًا، دون نسخ التطبيق أو تحويل مشروع TaL3D إلى ملخص أخبار عام.

- قراءة المقال الكامل باستخدام trafilatura مع العودة الآمنة إلى موجز RSS عند عدم إتاحته.
- عدم فتح روابط مقالات خارج قائمة نطاقات المصادر الرسمية المسموح بها، مع حدود حجم وزمن للطلبات.
- إعادة تحليل الأخبار القديمة حتى لو أعاد RSS استجابة 304 (Not Modified)، بعد رفع نسخة الاستخراج.
- تجميع المرادفات والعناوين الجزئية للقطعة نفسها؛ تحفظ السجلات القديمة بحالة superseded ولا تعد فرصًا مستقلة.
- فصل قائمة الفرص المرشحة عن رصد الأخبار في تقرير HTML عربي فاتح، مع صور الخبر الأصلية المصغرة وروابط الأدلة.
- ملف المعاينة reports/preview.html يُولد من Workflow مستقل بلا رسائل بريد، وحالة الاختبارات في data/preview_status.txt.
- الجمع المجدول لا يمنح ترخيصًا لنسخ العلامات أو المجسمات الرسمية. الطلب والمنافسة وحقوق التصميم تحتاج إثباتًا منفصلًا.

هذه مرحلة تحسين كشف النصوص وليست نظام تحليل صور، أو طلب اجتماعي متحقق، أو مسح شامل لكل أسواق STL.
